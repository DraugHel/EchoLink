# E3 Reload Completion Test

Approval und Abschlussnachricht bleiben nach einem Reload dauerhaft sichtbar.

Regeln:
- Nutze zwingend `e3_prepare_change`.
- Verwende genau eine `create_file`-Operation.
- Ändere keine andere Datei.
- Nutze kein Terminal, kein Git und keinen direkten Dateizugriff zum Schreiben.
- Nicht committen, pushen, deployen oder produktiv anwenden.
- Nach erfolgreicher Validierung die E3-Approval-Karte anzeigen und auf meine Entscheidung warten.
